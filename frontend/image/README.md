# 📷 Folder Foto Slider (image/)

Foto slider di halaman **#home** dibaca otomatis dari folder ini oleh backend
(endpoint `/api/images`).

## Cara menambah foto

1. Masukkan file foto ke folder ini (format **JPG, PNG, WEBP, atau GIF**).
2. Beri nama bebas, misalnya `ibadah-1.jpg`, `puji-pujian.png`.
3. Muat ulang halaman — foto langsung muncul di slider secara otomatis.

> Urutan tampil mengikuti urutan abjad nama file. Jika ingin diurutkan,
> beri awalan angka, contoh: `01-ibadah.jpg`, `02-pujian.jpg`.

## Catatan

- File `.svg` di folder ini hanyalah **placeholder contoh** dan boleh dihapus.
- Foto direkomendasikan berukuran landscape (rasio 4:3, mis. 1200×900)
  agar tampil optimal.
